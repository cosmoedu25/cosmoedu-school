대안학교에 딱 맞는
수업 특징

AI 크리에이티브
생성형 AI 도구로 그림책·음악·영상을 직접 창작합니다. 결과물이 곧 포트폴리오가 됩니다.
학교 철학 맞춤 설계
획일적인 커리큘럼이 아닌, 각 학교의 교육철학에 맞게 수업 주제와 방식을 함께 설계합니다.
STEAM 융합 수업
과학·역사·미술·음악과 코딩을 융합한 프로젝트 기반 수업으로 폭넓은 사고력을 기릅니다.
작품 자동 포트폴리오
수업 중 만든 작품이 클라우드에 자동 저장되어 별도 정리 없이 포트폴리오로 누적됩니다.
원격 전문 강사
전문 강사가 원격으로 수업을 진행합니다. 장소 제약 없이 어디서든 수업이 가능합니다.
기기 렌탈 옵션
노트북이 없어도 됩니다. 임대형·인수형 렌탈로 최소 5대부터 도입 가능합니다.
